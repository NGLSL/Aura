# Aura v0.3.0

首个私有仓库安装版。安装包包含 Aura 图形界面、EnvBox 命令行与 Broker、环境探针，以及 x64/x86 Runtime DLL。

## 本版内容

- 按应用配置环境 Profile，在目标进程树中提供 Locale、Region、UI Language、Timezone、DNS 视图等环境信息；宿主 Windows 的全局设置保持不变。
- 整理应用列表与配置界面的操作路径，加入 Aura 单例启动限制。
- 关闭 Aura 时可选择退出或最小化到系统托盘，并记住选择。已启动的目标应用在 Aura 退出或安装升级后继续运行；重新打开 Aura 后无法接管之前脱离的实例。
- 修正 WindowsApps 应用的 AUMID 启动路径，并让安装包始终包含与当前代码一起构建的 Rust 程序和两种架构的 Runtime DLL。
- 增加私有仓库 CI 与 tag 发布流程；界面版本和安装程序登记版本都来自 Cargo workspace 版本。

## 升级与使用

下载安装包 `aura-setup.exe`，运行安装。需要核对文件时，使用同页的 `aura-setup.exe.sha256`，并在 PowerShell 中执行 `Get-FileHash .\aura-setup.exe -Algorithm SHA256`。

EnvBox 是进程级环境虚拟化启动器，不提供安全隔离。目标程序仍可访问当前用户的文件、网络和其他宿主资源。部分 WindowsApps 程序有自身的打包及启动限制，尚未逐个完成安装版手动验收。
