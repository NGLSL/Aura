# Aura v0.3.1

此版本修正按 Profile 启动 CLI 与子进程时的环境一致性，并扩展 Windows API 的 Locale、Timezone 和 DNS 虚拟视图。安装包包含 Aura、EnvBox CLI、Broker、环境探针及 x64/x86 Runtime DLL。

## 本版内容

- 应用可以保存 Direct、cmd.exe、PowerShell 或 Windows Terminal 启动方式。命令行应用默认从用户主目录启动；Windows Terminal 标签页通过独立交接进入对应实例的 Job，以便在 Aura 中查看和停止。
- 应用选择器能发现已安装的 CLI 命令，并改进应用图标的识别与显示。
- 修正 Profile 环境变量向受管理子进程的传递。完整 Profile 可用时，继承的 `LANG`、`LANGUAGE` 和 `LC_*` 会先被清理，再按 Profile 设置；UCRT 的空 locale 初始化也按 Profile 解析。显式指定的 CRT locale 不会被改写。
- 扩展 Locale、代码页、注册表和 WinRT 时区视图；同一 Profile 下的区域、语言和时区读取更一致，宿主全局设置保持不变。
- VirtualView DNS 下，受支持的异步 `DnsQueryEx` A/AAAA 查询使用 Profile DNS，并处理取消、回调重入和资源释放。DNS Hook 安装失败时仍按既有策略回退到原 Windows API。

## 验证与性能

- x64/x86 Runtime 的 Debug 和 Release 构建通过；工作区测试 301 通过、7 忽略。最终 Probe 参数调整后，DNS 测试 21/21、Probe 测试 9/9、CRT locale 测试 3/3 再次通过。
- 在安装了本次 Runtime 的新进程中，Probe 读到 `en-US` Locale、`America/Los_Angeles` WinRT 时区、`1.1.1.1` DNS，以及 `en_US.UTF-8` UCRT 空 locale 初始化结果；Codex、ChatGPT 和其 PowerShell 子进程加载了相同哈希的新版 DLL。
- 同机 Release CLI/Probe 交替测量 20 轮：空命令中位数为旧版 36.369 ms、新版 36.033 ms；完整 Probe 为旧版 139.095 ms、新版 170.572 ms。完整 Probe 新增了两次实际 CRT locale 初始化检查，因此该差值不是普通应用启动开销。

## 升级与已知边界

下载安装包 `aura-setup.exe` 并运行。需要核对文件时，下载同页的 `aura-setup.exe.sha256`，在 PowerShell 中运行 `Get-FileHash .\aura-setup.exe -Algorithm SHA256`。升级不会修改 Windows 全局 Locale、Region、Timezone 或 DNS。

`GetAddrInfoExA/W` 异步路径、`DnsQueryRaw`、应用自带的 DNS/DoH 解析器仍可能直接使用宿主网络。Broker 不可用时的回退环境信息不足以在应用修改自身环境后完整重建 Profile。EnvBox 不是安全沙箱；目标程序仍能访问当前用户的文件、网络和其他宿主资源。Windows Terminal 的实际桌面交互与安装升级需在目标机器上验收。
