# Aura v0.3.9

Aura gives application and environment configuration lists more room and remembers each page's pane proportions after restart. This release also separates GUI workflows and Windows command-line preparation into focused modules.

## Changes

- Applications and environment configurations now share a default split of 60% for the list and 40% for the detail panel, excluding the navigation bar.
- Dragging either page's divider saves its proportion to the existing user UI configuration. Each page remembers its own value; reopening Aura restores it. Existing saved proportions take precedence over the default.
- Older UI configuration files retain their remembered window-close behavior and receive the new default proportions. Saving close preferences preserves pane proportions, and resizing panes preserves close preferences.
- GUI application operations, environment configuration editing, unsaved-edit navigation, and audit loading now live in separate modules. The DNS form depends on its editor state and DNS mode rather than the complete application state.
- Windows argument parsing, quoting, ComSpec preparation, and activation-program resolution now live in a dedicated launcher module. Public entry points, argument rules, and process injection behavior are preserved.

## Validation and limitations

- Regression coverage exercises default proportions on both pages, independent resizing, application reconstruction, and preservation of close preferences. Configuration coverage also checks older files and invalid proportions.
- Existing argument parsing and ComSpec tests follow the extracted implementation. Publication requires successful Windows CI for the exact release commit, including workspace tests and the separate CPU-renderer regression suite.
- Build, test, and published-installer verification do not establish manual drag/restart behavior in an installed GUI, elevated in-place upgrades, or physical-monitor behavior. Those remain separately unverified for this release.
- Aura remains a process-scoped environment launcher, not a security sandbox. Existing Runtime and application compatibility limitations continue to apply.

## Upgrade

Run aura-setup.exe or use the updater, then reopen Aura. Existing applications, environment configurations, and UI close preferences are retained. Previously saved divider proportions are restored; when no proportions were saved, both pages use the new 60% / 40% default.
