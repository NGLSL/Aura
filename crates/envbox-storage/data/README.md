# Unicode CLDR 48 timezone mappings

Pinned source: Unicode CLDR `release-48`.

- https://github.com/unicode-org/cldr/blob/release-48/common/supplemental/windowsZones.xml
- https://github.com/unicode-org/cldr/blob/release-48/common/bcp47/timezone.xml

The TSV files are mechanical projections of `mapZone` attributes and BCP47 timezone alias groups. The original XML and Unicode license are included for attribution and reproducibility. No timezone is inferred from a country, offset, or city.
