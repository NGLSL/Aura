# 28: 文件删除、rename/replace与合并枚举原型

Stage: P5
Status: ready-for-agent
Parent: [总规格](../spec.md) · [完整实施规划](../implementation-plan.md)

**What to build:** 在host/A/B夹具验证删除遮蔽、原子保存及目录视图，不让删除项重现或修改宿主。

Blocked by: [27](./27-ticket.md)

## 负责模块与契约

文件overlay命名空间/whiteout/枚举原型及fixture客户端。

保持总规格的稳定Container/Instance身份、不可变Run快照和host/A/B独立对照。修改限定于本票职责；保留其他Agent改动。关键契约变化或未证明机制需报告证据，由主Agent决定，不静默降级。

## 不包括

不支持跨卷操作自动回退，不提前承诺通知和所有Windows文件系统。

## 验收标准

- [ ] 删除host项只产生A的遮蔽，host/B仍可见；删除私有项、重建同名与目录删除语义一致。
- [ ] 同作用域rename、replace及临时文件原子保存不改变host；跨规则/跨卷操作拒绝或遵守已证明显式规则。
- [ ] 合并枚举去重并遮蔽whiteout，大小写、排序契约、分页/小buffer及继续枚举可重复验证。
- [ ] 打开句柄与删除/重命名并发、共享限制和失败返回保持一致，不出现host路径回写。
- [ ] 崩溃/重开后目录状态和whiteout可靠恢复，已删除项不复活；记录原始host/A/B目录结果。

## 验证证据

经公共CLI、真实注入/内核Probe或本票指定的资格入口验证可观察行为，保存配置快照、系统/组件版本、模块路径与hash、host/A/B原始结果和失败原因。需要驱动、故障或危险系统配置的验证只在明确隔离测试环境执行；本票不授权宿主安装、外部申请或发布。静态检查、fixture、隔离环境、实际安装与真实应用证据分别列出；未执行、缺材料、权限不足及skip不得算通过。文档预检票保存可复现检查与来源，不伪造运行证据。
