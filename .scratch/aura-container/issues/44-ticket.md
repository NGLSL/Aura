# 44: 安装、升级、卸载与回滚完整包

Stage: P7
Status: ready-for-agent
Parent: [总规格](../spec.md) · [完整实施规划](../implementation-plan.md)

**What to build:** 在指定隔离环境证明正式组件安装与维护可恢复，保留活动实例和私有数据的版本契约。

Blocked by: [43](./43-ticket.md)、[13](./13-ticket.md)、[41](./41-ticket.md)

## 负责模块与契约

安装/升级/卸载事务、驱动服务生命周期及隔离环境资格测试。

保持总规格的稳定Container/Instance身份、不可变Run快照和host/A/B独立对照。修改限定于本票职责；保留其他Agent改动。关键契约变化或未证明机制需报告证据，由主Agent决定，不静默降级。

## 不包括

不隐含宿主实装授权，不删除用户Container数据，不自动绕过签名/安全要求。

## 验收标准

- [ ] 指定隔离环境完成干净安装与能力预检，签名/系统/协议不合格在改变系统前或可回滚阶段拒绝。
- [ ] 活动实例升级保留所需Runtime及策略版本，不兼容接续明确阻塞或按授权停机流程执行，不能清掉旧bundle。
- [ ] 安装/升级各失败点回滚组件与服务状态，不破坏已有Container/共享目录，记录重启要求及恢复步骤。
- [ ] 卸载先确认活动资源释放，安全移除驱动/过滤策略与控制组件；私有数据保留或通过独立明确操作清除。
- [ ] 隔离环境OS重启、Secure Boot/HVCI组合与升级后再运行有实际证据；缺正式签名或指定环境保持阻塞，不用mock替代。

## 验证证据

经公共CLI、真实注入/内核Probe或本票指定的资格入口验证可观察行为，保存配置快照、系统/组件版本、模块路径与hash、host/A/B原始结果和失败原因。需要驱动、故障或危险系统配置的验证只在明确隔离测试环境执行；本票不授权宿主安装、外部申请或发布。静态检查、fixture、隔离环境、实际安装与真实应用证据分别列出；未执行、缺材料、权限不足及skip不得算通过。文档预检票保存可复现检查与来源，不伪造运行证据。
