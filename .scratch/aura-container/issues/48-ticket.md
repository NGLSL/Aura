# 48: 长期运行与资源性能报告

Stage: P8
Status: ready-for-agent
Parent: [总规格](../spec.md) · [完整实施规划](../implementation-plan.md)

**What to build:** 测量完整Container实际长期行为和资源开销，给出有环境、基线及原始数据的产品限制。

Blocked by: [46](./46-ticket.md)、[47](./47-ticket.md)

## 负责模块与契约

受控长跑/性能采样、后台及应用归因报告。

保持总规格的稳定Container/Instance身份、不可变Run快照和host/A/B独立对照。修改限定于本票职责；保留其他Agent改动。关键契约变化或未证明机制需报告证据，由主Agent决定，不静默降级。

## 不包括

不沿用20–50MB推测，不用低占用替代正确性，不无界占用用户主机。

## 验收标准

- [ ] 约定并记录受控时长、工作负载、采样频率及停止条件，覆盖空闲、单实例、多实例与反复启动/停止/重连。
- [ ] 分别测private working set、total working set、private commit、handle/线程及磁盘私有状态，不混淆控制面和目标应用增量。
- [ ] 启动/重连/Stop、DNS及关键I/O的延迟与吞吐有基线及分布，记录系统、模块hash、快照和原始样本。
- [ ] 长跑中身份/策略/数据隔离和故障恢复持续抽验，出现泄漏、增长或错误时记录复现并阻塞资格。
- [ ] 报告只给实测数值、样本限制与已验证容量，不编造统一性能阈值或无证据稳定性保证。

## 验证证据

经公共CLI、真实注入/内核Probe或本票指定的资格入口验证可观察行为，保存配置快照、系统/组件版本、模块路径与hash、host/A/B原始结果和失败原因。需要驱动、故障或危险系统配置的验证只在明确隔离测试环境执行；本票不授权宿主安装、外部申请或发布。静态检查、fixture、隔离环境、实际安装与真实应用证据分别列出；未执行、缺材料、权限不足及skip不得算通过。文档预检票保存可复现检查与来源，不伪造运行证据。
