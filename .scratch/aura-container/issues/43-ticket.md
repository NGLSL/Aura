# 43: 正式签名与发布交付准备

Stage: P7
Status: ready-for-agent
Parent: [总规格](../spec.md) · [完整实施规划](../implementation-plan.md)

**What to build:** 产出可审阅的正式驱动交付候选包和签名资格报告，把外部依赖作为明确发布门禁。

Blocked by: [21](./21-ticket.md)、[38](./38-ticket.md)

## 负责模块与契约

驱动release构建/包清单/签名验证与交付资格文档。

保持总规格的稳定Container/Instance身份、不可变Run快照和host/A/B独立对照。修改限定于本票职责；保留其他Agent改动。关键契约变化或未证明机制需报告证据，由主Agent决定，不静默降级。

## 不包括

不擅自对外提交、申请证书/altitude、发布或安装宿主驱动。

## 验收标准

- [ ] release候选构建可复现，记录来源commit、驱动/用户态协议版本、包hash、INF及依赖清单。
- [ ] 按当前官方政策检查正式签名、Partner Center/证书、HLK/WHCP路径及altitude条件，测试签名不记正式合格。
- [ ] 安全加载/卸载及Secure Boot/HVCI要求形成可执行资格清单，已验证与待提供材料分开。
- [ ] 可信更新验证拒绝篡改/不兼容包，签名或协议失败不安装、不启动Container且保持现有数据。
- [ ] 外部材料缺失时交付明确阻塞与可审候选，43不得按正式签名完成；后续对外操作须另有授权。

## 验证证据

门禁：候选包和资格报告不等于正式签名交付完成。缺外部正式签名材料/资格时本票保持条件阻塞，44不能以测试签名替代正式交付链验收。

经公共CLI、真实注入/内核Probe或本票指定的资格入口验证可观察行为，保存配置快照、系统/组件版本、模块路径与hash、host/A/B原始结果和失败原因。需要驱动、故障或危险系统配置的验证只在明确隔离测试环境执行；本票不授权宿主安装、外部申请或发布。静态检查、fixture、隔离环境、实际安装与真实应用证据分别列出；未执行、缺材料、权限不足及skip不得算通过。文档预检票保存可复现检查与来源，不伪造运行证据。

最终验收关联：F08（见[实施规划最终验收](../implementation-plan.md#最终验收)）。
