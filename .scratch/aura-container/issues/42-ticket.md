# 42: 停机导出、导入与版本校验

Stage: P7
Status: ready-for-agent
Parent: [总规格](../spec.md) · [完整实施规划](../implementation-plan.md)

**What to build:** 停止环境可导出私有状态和清单，再导入为独立身份，并拒绝危险或不兼容包。

Blocked by: [40](./40-ticket.md)、[41](./41-ticket.md)

## 负责模块与契约

数据包格式、版本验证、CLI导入导出事务与恶意fixture。

保持总规格的稳定Container/Instance身份、不可变Run快照和host/A/B独立对照。修改限定于本票职责；保留其他Agent改动。关键契约变化或未证明机制需报告证据，由主Agent决定，不静默降级。

## 不包括

不导出宿主或共享目录内容，不提供在线一致性，不覆盖已有Container。

## 验收标准

- [ ] 导出要求停止且所有引用释放，仅含私有文件/Registry/tombstone、配置与版本清单，明确lazy host依赖及共享引用。
- [ ] 导入验证schema/backend能力、大小、路径穿越、绝对路径、链接与ACL，危险包拒绝且外部哨兵不变。
- [ ] 新UUID与管理根生成，不沿用旧Run/PID归属；缺失Profile/共享路径需明确解决而非猜测公共配置。
- [ ] 失败/磁盘满/中断不覆盖已有环境、不发布半成品，临时资源安全清理或可恢复。
- [ ] 真实导出→导入→运行验证私有数据、删除标记与A/B/host独立，未知版本保留明确错误。

## 验证证据

经公共CLI、真实注入/内核Probe或本票指定的资格入口验证可观察行为，保存配置快照、系统/组件版本、模块路径与hash、host/A/B原始结果和失败原因。需要驱动、故障或危险系统配置的验证只在明确隔离测试环境执行；本票不授权宿主安装、外部申请或发布。静态检查、fixture、隔离环境、实际安装与真实应用证据分别列出；未执行、缺材料、权限不足及skip不得算通过。文档预检票保存可复现检查与来源，不伪造运行证据。
