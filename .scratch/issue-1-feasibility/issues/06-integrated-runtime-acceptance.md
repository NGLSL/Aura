## 交付行为

用户可以完成“选择中文地区 → 查询并保存出口时区 → 选择独立 Chrome 目录并启动 → 打开检测页 → 退出 Aura 界面 → 继续使用 Chrome”的完整流程。首版验收对照规格 A1–A13，实际运行与未验证项各有记录。

## 验收条件

- [x] 汇总各功能票的有效证据，对照规格 A1–A13 标明已验证、部分验证、未验证及实际失败；不机械重复同一候选和输入的有效检查。
- [x] 实际完成中文地区选择/搜索、当前网络查询和指定出口查询、双时区预览/保存、新启动实例读值；确认保存的 ISO/Windows/IANA 标识与原契约一致。
- [x] 实际完成普通 Run、Run With、Workspace 相关的目录解析与检测页面流程，核对可见窗口、根进程、目录及启动配置；Profile 和 Host 的证据要求分开记录。
- [x] 真正退出 Aura 界面后，Profile Chrome 仍能新建标签页/窗口及必要后继进程，保持启动时语言和时区；Host Chrome 正常续用并保持宿主环境。仅最小化到托盘不计通过。
- [x] 对照未注入 Host，确认宿主全局设置和普通 Chrome 未被本功能改变；使用真实窗口与进程归属证据，不以孤立 Probe 成功代替 Chrome 场景。
- [x] 复用已有 detached-session 检查核对后继创建与会话后台清理，且不把该脚本当作 Chrome 交互已通过的证据；保留用户正在使用的无关进程。
- [x] 复用已有构建、类型/静态检查和适用的现有检查；禁止编写测试用例。单独报告旧地区标签断言冲突，不将失败或未执行项列为通过。
- [x] 查询服务或检测站不可用时，配置及已运行实例保持可用；未能实际触发的服务异常或未测架构如实标注，不由第三方评分决定通过。
- [x] 将组合过程发现的必要修复交回对应功能票负责人并复核结果；验收缺口未解决时不关闭本票，不用修改规格削弱原契约。
- [x] 完成与首版实际行为一致的中文使用说明：时区查询来源、分流时指定 IP、独立目录首次使用、两个检测入口，以及退出界面与会话后台的区别。

本票负责组合与实际续用证据，不另写网络客户端、Chrome 目录状态机或新生命周期平台。前置 03 已传递包含 02，05 已传递包含 04。

保存可复用的验收记录并链接回任务地图；只有实际验收允许的功能才标为完成。代码实现结束后的审查和当前分支提交按用户指定的 implement 流程进行；本票不授权推送、发版或部署。
