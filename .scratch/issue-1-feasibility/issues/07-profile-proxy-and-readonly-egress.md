# 07：只读实际出口与 Profile HTTP/SOCKS5 代理

Parent: [规格](../spec.md)
Status: resolved
Category: enhancement
Blocked by: 02, 04, 05

## 用户决定

用户要求出口 IP 必须实际检测、不可编辑；已确认 Chrome 和出口检测共同使用 Profile 的 HTTP/SOCKS5 代理。本票替换原 03 的指定 IP 交互，不把旧行为继续作为新版本验收目标。

## 完成条件

- [x] 删除指定 IP 输入及查询来源选择；只显示实际响应 IP，保留时区预览、填入、保存分离。
- [x] Profile 代理可编辑、验证、保存、重开；无代理旧配置保持原网络语义。服务器地址/端口只用于代理，不作为出口 IP。
- [x] 同一 Profile 的普通 Run/Run With/Workspace Chrome 和查询使用相同 HTTP/SOCKS5 端点；SOCKS5 为远端 DNS，无自动直连回退，Host 不继承 Profile 代理。
- [x] 代理与应用手填代理控制参数冲突时拒绝；未配置 Profile 代理时不扩大旧应用前置条件。
- [x] 代理变化使旧查询结果失效；完整实例配置比较拒绝将新代理检测页转交给旧代理浏览器。
- [x] 只填入两个时区字段；查询错误不覆盖 Profile，不改 Windows 全局代理/时区，不实现任意进程代理或 UDP 全流量保证。
- [x] 实际使用现有本机 HTTP/SOCKS5 代理核对查询结果、Chrome 参数与网页；代理失败路径和查询只读 UI 留证据；不更改代理服务配置或无关程序。
- [x] 复用已有定向构建与检查，禁止新增测试用例；完成审查、中文说明和当前分支提交，不推送或发布。

## 实施边界

一个实现负责人贯通 Profile 模型、参数合成与编辑/查询状态。主 Agent 负责规格、说明、实际运行和最终验收。Chrome 默认渠道目录 P2 由原启动负责人先修复并交还文件，再由本票接入代理参数，避免共享写区冲突。

本轮只配置无认证代理端点，不保存秘密，不新增本地中继、浏览器扩展或 Runtime Hook。服务端数据与浏览器分流仍分别说明，不能把相同代理配置夸大为对所有网站出口的一致性保证。
