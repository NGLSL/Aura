# 03：按指定公网出口 IP 查询时区

Parent: [浏览器环境配置与检测](../spec.md)
Status: resolved
Category: enhancement
Blocked by: 02

## 交付行为

使用分流代理的用户从检测页确认目标出口 IP，在 Profile 编辑器选择“指定出口 IP”，查询该地址的具体时区并预览填入，不会被 Aura 自己的网络出口替换。

## 验收条件

- [x] 增加指定出口 IP 输入，按规格使用 Net.Coffee 固定服务查询该地址；不增加自定义服务 URL 或供应商切换设置。
- [x] 接受合法公网 IPv4、IPv6 并规范化后构造请求；私有、回环、链路本地、组播、未指定等非公网地址，以及域名、URL、带端口输入不得发起查询。
- [x] 结果始终绑定本次输入；响应如包含 IP，须与请求一致。失败时不改用当前网络接口重新探测，也不替换成 Aura 自己的出口。
- [x] 只使用响应的具体 timezone；不能将检测页的国家代表时区、城市名称或 UTC 偏移作为自动填入值。缺失或无法映射时保留原配置并显示原因。
- [x] 复用 02 的预览、双字段填入、保存、超时/大小限制及迟到结果失效规则；切换来源或修改 IP 后旧结果不可继续应用。
- [ ] 查询服务不支持某个合法地址时明确失败，不把无记录、接口变化或 IPv6 未支持显示成成功。
- [ ] 实际查询一个用户确认的出口，核对请求 IP、返回时区、预览及保存结果；分别记录实际完成的 IPv4/IPv6 证据和未验证分支。

## 边界与交接

不读取代理扩展或分流配置，不自动抓取检测页面，不要求 05 完成才可查询：用户可以自行打开检测站并复制 IP。

对应规格 A2、A3 和 A9 的指定 IP 查询失败部分。向 06 交付来源切换、指定出口及保存行为证据，不能将一个地址的成功推广为全部服务或协议分支通过。

## Comments

### 2026-10-16：指定 IP 流程已实现，待用户出口及 GUI 验收

- 指定输入先解析 `IpAddr` 并拒绝私有、回环、链路本地、组播、未指定、文档/保留等非公网值。IPv6 包含 IANA 公网特殊分配例外；输入网址、域名、端口无法通过解析。固定 Net.Coffee 路径只由规范化 IP 构造。
- 查询结果绑定本次输入；响应如有 IP，解析后必须与请求地址一致；不会改用 IPPure 或 Aura 当前出口。具体时区缺失或映射无效时保留可见预览并禁用填入。
